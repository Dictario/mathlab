Special points

Sliders are created automatically for single letters in your formulas (a, b, c, k…); create longer names such as speed with “+ Slider”. Functions can call each other: define g(x) = f(x) + 1 in the input bar. Equations like x^2 + y^2 = 4 draw implicit curves. Use ^ for powers, 2x for products, pi and e as constants.
